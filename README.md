# 주방 타이머

iPhone에서 메뉴(이름·아이콘·색·조리 단계)를 관리하고, Apple Watch에서 골라 큐에 넣어 동시에 돌리는 주방 타이머.

## 구조

| 폴더 | 내용 |
|---|---|
| `Shared/` | 메뉴·타이머 모델, 알림 감지 로직, 폰→워치 동기화. 두 앱과 테스트가 같이 컴파일 |
| `KitchenTimer/` | iPhone 앱: 메뉴 목록·편집 |
| `KitchenTimerWatch/` | 워치 앱: 큐(완성 고정·긴급도 색·촘촘한 목록), 상세(크라운·+1분), 단계 띠, 스마트 알람, 시리 |
| `KitchenTimerTests/` | 단위 테스트 (Swift Testing, 앱 실행 없이 로직만) |
| `Config/` | 워치 Info.plist(스마트 알람 백그라운드 모드), 앱 아이콘 생성 스크립트 |

```bash
xcodebuild test -project KitchenTimer.xcodeproj -scheme KitchenTimerTests -destination 'platform=iOS Simulator,name=iPhone 18 Pro Max'
```

앱 아이콘은 `swift Config/render-app-icon.swift icon.png`로 다시 만들 수 있다.

## 식당 모드

메뉴 페이지 맨 아래 **식당 모드 › 화구 번호 묻기**를 켜면, 메뉴를 고를 때 화구 번호(기본 6개, 2~9개)를 큰 버튼으로 고른다.
냄비가 올라간 화구는 흐리게 🔥 표시되고, 목록에는 번호 배지가 붙는다(알림·시리에서는 "3번 파스타").

- **하나 더**: 큐 화면 왼쪽 위 ↻ 버튼. 마지막에 넣은 메뉴를 다시 넣는다.
- **빠른 추가**: 큐 목록 맨 아래. 많이 쓴 메뉴 4개를 한 번에 누른다.
- **메뉴 페이지**: 많이 쓴 순서로 정렬된다.
- **손목 내려도 계속 울리게**: 식당 모드를 처음 켜면 워치의 "시계로 돌아가기"를 이 앱만 1시간으로 바꾸는 방법을 안내한다(설정 앱 › 일반 › 시계로 돌아가기 › 주방 타이머 › 사용자 설정 › 1시간 후). 앱이 계속 앞에 있으면 연달아 끝나는 타이머도 매번 앱 안에서 울린다. 같은 안내는 식당 모드 항목에서 다시 볼 수 있다.

## 단계가 있는 메뉴

스테이크(앞면 → 뒷면)처럼 단계가 있으면, 한 단계가 끝나도 다음 단계가 저절로 시작되지 않는다.
목록 맨 위에 "앞면 끝 → 뒷면 3:00" 빨간 줄이 생기고 끝난 뒤 지난 시간을 센다. 뒤집은 뒤 줄을 탭(또는 더블 탭)하면 그때부터 뒷면을 센다.
알림의 "다음 단계 시작" 버튼으로도 된다. "1분 더"는 지금 단계를 지금부터 1분 더 익힌다.

## 알림이 울리는 방식

| 상황 | 동작 |
|---|---|
| 앱을 보고 있음 | 단계 끝: 위에 띠가 4초 뜨고 사라짐(확인 불필요). 완성: 목록 맨 위 빨간 줄로 고정, +시간 초과를 셈, 0·2·4초 진동 후 30초마다 다시 진동. 줄을 탭하거나 더블 탭으로 확인 |
| 손목을 내림 | 스마트 알람이 시스템 알람 화면 + 반복 진동. "열기"를 누르면 앱 안 알림으로 이어짐 |
| 알림 권한 꺼짐 | 스마트 알람은 그대로 울림. 큐 화면에 "알림이 꺼져 있어요" 표시 |

스마트 알람은 앱이 활성 상태일 때만 예약할 수 있어서, 타이머를 추가·조정할 때와 앱이 다시 보일 때 다음 알림 시각에 맞춰 건다.
한 번에 하나만 걸 수 있으므로, 손목을 내린 채 두 번째 타이머까지 끝나면 두 번째는 일반 알림(진동 1회)으로 온다.

## 실기기에서 꼭 확인할 것

- [ ] 디지털 크라운 ±10초 조정, 조정량 표시
- [ ] 더블 탭으로 알림 확인 / 상세 화면에서 +1분
- [ ] 반복 진동 세기가 주방 소음 속에서 충분한지
- [ ] 손목을 내린 채 두 타이머가 연달아 끝날 때 두 번째 알림 ("시계로 돌아가기 1시간" 설정 전/후 비교)
- [ ] 안내 화면의 설정 경로·메뉴 이름이 실제 워치 설정과 같은지
- [ ] 시리: "주방 타이머에서 파스타 시작해", "주방 타이머 남은 시간 알려줘"
- [ ] 폰에서 메뉴 수정 → 워치 반영 (시뮬레이터의 새 페어링에서는 워치 앱 설치 인식 문제로 확인 못 함)
- [ ] 집중 모드에서도 알림이 오도록 하려면 Time Sensitive Notifications capability 추가
