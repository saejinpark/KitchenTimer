# 심사용 실기기 녹화 촬영 순서

애플 요구: 실기기·최신 OS, **앱 실행부터 시작**해서 일반적인 사용 흐름을 보여줄 것.
워치는 기기 자체 화면 녹화가 없어서, **iPhone 화면 녹화 + 다른 폰으로 워치를 찍은 영상**을 이어 붙이거나 한 화면에 나란히 두면 된다.

## 준비

- iPhone: 설정 › 제어 센터에 "화면 기록" 추가
- 워치: 화면이 잘 보이게 밝은 곳, 다른 폰(또는 카메라)으로 촬영
- 빨리 끝나게 iPhone에서 테스트 메뉴 하나를 **앞면 10초 → 뒷면 10초**로 만들어 두기 (영상 뒤에는 원래대로)
- 진행 중인 타이머는 모두 지우고 시작

## 촬영 순서 (2~3분)

1. **iPhone 화면 기록 시작 → 홈 화면에서 주방 타이머 실행**
2. 메뉴 목록 → 스테이크(또는 테스트 메뉴) 눌러 아이콘·색·조리 단계 편집 화면 보여주기
3. 단계 하나 눌러 시간 휠로 바꾸기 → 완료 → 목록으로
4. **워치 촬영 시작 → 워치에서 주방 타이머 실행** (처음이면 알림 허용)
5. 아래로 넘겨 메뉴 페이지 → 라면 눌러 시작 → 큐로 돌아오는 것 보여주기
6. 테스트 메뉴(10초+10초) 추가
7. 타이머 하나 눌러 상세 화면 → 크라운 돌려 시간 조정, 60초 버튼 눌러 1분 추가 → 뒤로
8. 테스트 메뉴 앞면이 끝나면 맨 위 빨간 줄 "앞면 끝 → 뒷면 0:10" → 줄 눌러 뒷면 시작
9. 뒷면이 끝나면 "완성 · 탭하면 확인" 빨간 줄 → 눌러서 확인 → 목록에서 빠지는 것까지
10. (선택) 식당 모드 켜고 화구 번호 고르는 화면

## 올리기

- 파일이 크면 iPhone 사진 앱에서 다듬기로 앞뒤를 자르고, 워치 영상과 이어 붙인 한 파일로 만든다.
- App Store Connect › 앱 심사 정보 › **첨부 파일**에 영상 파일을 올리고 저장 → "심사에 추가"로 다시 제출.
- 파일을 이 폴더(예: `AppStore/review-video.mov`)에 넣어 주면 업로드는 대신 해 줄 수 있다.
