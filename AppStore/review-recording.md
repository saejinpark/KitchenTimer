# 심사용 실기기 녹화 촬영 순서

애플 요구: 실기기·최신 OS, **앱 실행부터 시작**해서 일반적인 사용 흐름을 보여줄 것.
폰과 워치를 한 화면에 같이 담기 위해 Mac에 두 실기기 화면을 나란히 띄우고 Mac 화면을 녹화한다.

## 준비

- **iPhone**: Mac에서 iPhone 미러링 앱 실행 (iPhone은 잠긴 채로 가까이 두기)
- **워치**: Xcode › Window › Devices and Simulators › 워치 선택 › View Screen
- 두 창을 나란히 배치 (왼쪽 iPhone, 오른쪽 워치), 나머지 창은 숨기기
- 빨리 끝나게 iPhone 앱에서 테스트 메뉴 하나를 **앞면 10초 → 뒷면 10초**로 만들어 두기 (영상 뒤에는 원래대로)
- 워치에 진행 중인 타이머는 모두 지우고, 두 앱 모두 완전히 종료해 두기
- 녹화: `⌘⇧5` › "선택 부분 기록"으로 두 창이 들어가게 영역 지정 (소리 필요 없음)

## 촬영 순서 (2~3분)

1. 녹화 시작 → **미러링된 iPhone 홈 화면에서 주방 타이머 실행**
2. 메뉴 목록 → 스테이크(또는 테스트 메뉴) 눌러 아이콘·색·조리 단계 편집 화면
3. 단계 하나 눌러 시간 휠로 바꾸기 → 완료 → 목록으로 (워치에 동기화됨)
4. **워치에서 주방 타이머 실행** (처음이면 알림 허용)
5. 아래로 넘겨 메뉴 페이지 → 라면 눌러 시작 → 큐로 돌아오는 것
6. 테스트 메뉴(10초+10초) 추가
7. 타이머 하나 눌러 상세 화면 → 크라운 돌려 시간 조정, 60초 버튼으로 1분 추가 → 뒤로
8. 테스트 메뉴 앞면이 끝나면 맨 위 빨간 줄 "앞면 끝 → 뒷면 0:10" → 줄 눌러 뒷면 시작
9. 뒷면이 끝나면 "완성 · 탭하면 확인" → 눌러서 확인 → 목록에서 빠지는 것까지
10. (선택) 식당 모드 켜고 화구 번호 고르는 화면

## 올리기

- 앞뒤 불필요한 부분은 QuickTime › 편집 › 다듬기로 자른다.
- App Store Connect › 앱 심사 정보 › **첨부 파일**에 영상을 올리고 저장 → "심사에 추가"로 다시 제출.
- 파일을 이 폴더(예: `AppStore/review-video.mov`)에 넣어 주면 업로드는 대신 해 줄 수 있다.
